Manual

Everything the machine does, and how to take what it makes into the rest of your work.

Start here

Create-o-matic has two instruments so far: Motion, for type and marks that move, and the Texture lab, for treating images and video. They share the same controls, patches, keyframes and exports. Open Motion. On the left is the stage: the loop, a play button, and the playhead. On the right is the rack of controls, in groups. Everything you change is kept in the page's address as you go, so a reload never loses work and the address bar is always a link to exactly what's on screen.

  1. Pick a preset from Presets, or start from what's there.
  2. Change the words in Content, one per line.
  3. Pick a Format: 9:16 for Reels and Stories, 4:5 for the feed, 16:9 for YouTube, A3 for print.
  4. Press Vary a few times. It deals a new grid and motion and leaves your type, colour and format alone.
  5. Export: MP4 for social, PNG for a still.

The rack's groups have workshop names, each with a plain description beside it: Patch bay (presets and saving), Paper (size and time), Type case (words, marks, fonts), Loom (the grid), Stencil (shape fill), Clockwork (motion and keyframes), Ink well (colour), Stage (gradient, image, video), Darkroom (effects) and Print shop (export). Hover any control's name for what it does.

Keyboard: Space plays and pauses, ← and → step a frame. Drop a font, an SVG, an image, a video or a patch anywhere on the page.

The Texture lab

The Texture lab is a darkroom for any image or video. Drop a file anywhere on the page and it's on the Light table; the frame takes its exact size (up to 6,000 pixels on the long side; export at double for more). Choose another Format to reframe it, for instance a landscape video as 9:16. Zoom and Pan can be keyframed for a slow camera move across a still.

The stack

The Darkroom is a stack of layers, applied from the top down. Add an effect… puts a new layer at the bottom. On each layer: the dot switches it on and off, the arrows move it, × removes it, and its name opens its settings, including a Blend mode and Opacity. The same effect can be used as many times as you like.

ColourAdjust (brightness, contrast, saturation, hue, warmth), Gradient map (duotones and tritones), Acid, Holographic foil, Invert, Posterize.
PrintRisograph (two to four drums, misregistration, dot grain), Halftone, Photocopy, Paper (uncoated, kraft, newsprint, card, blotting).
TextureChroma split, Film (halation, fade, vignette), Grunge (dust, scratches, stains), Grain.
PaintGradient (mesh, linear or radial) and Texture overlay: your own scan, photograph or light leak, blended in.
Distort and mountKaleidoscope, Liquid, Melt, Reflector, Cube, Pin button.

Blend modes work as they do in Photoshop. Multiply for paper, dirt and ink. Screen for light leaks, dust on black and glows. Overlay and Soft light for gradients and colour washes. Colour and Luminosity to move just the hue or just the tone.

The textures are generated in code from the seed, so they're original, never repeat, and come out the same every time. Reroll gives you new dust, fibre and grain without changing anything else. For your own textures, add a Texture overlay layer and choose the file; photographs of real paper, risograph prints and photocopies make the best ones.

Presets here are looks: choosing one changes the stack and keeps your image. Vary nudges every setting in the stack a little either way. A video plays through its loop, and every exported frame waits for the video to reach its exact time.

Type and marks

Each line of Content is a slot. Content mode decides which slot goes in which cell:

By sizeThe first line goes in the smallest cells, the last in the largest. Write S, M, L, XL and the words swap as cells grow.
In sequenceSlots in reading order.
LettersYour words spelled out, one letter per cell, across each row.
RandomA pick for each cell, decided by the seed.

Marks: logos and graphics

Drop an SVG on the page, or use Add mark… under Content. It becomes a line such as @studiolo, and from then on it behaves exactly like a word: it stretches, takes the inks, blends and goes through the effects. Marks fit can keep a logo's proportions; Marks colour can keep its own colours.

SVG gives the best result: it's drawn as vectors, sharp at any export size, and travels inside the patch. Only filled shapes come through, so outline strokes and text first (in Illustrator: Object › Expand and Type › Create Outlines). PNG and JPEG work too: transparent images use their alpha as the shape, opaque ones use their darkness. Those stay in your browser rather than in the patch.

Fonts

Press Browse beside Family to search everything the machine can reach, each name set in its own face:

  • Font library: every Google family and about 120 more open-source faces, around 2,100 in all, served by Fontsource. Free to use and ship.
  • Adobe kit: the families in your own Adobe Fonts web project. Choose the source, enter the project ID, and add this site's domain to the project in Adobe Fonts.
  • Installed: fonts on your computer (Chrome and Edge ask permission first). Fine for exports; an embed on your website can't use them.
  • My fonts: font files you add, from any foundry. They stay in this browser.

With a variable font, set Weight, small and Weight, large apart and the weight follows the cell: light when it's squeezed, heavy when it swells.

Colour

Every swatch opens the picker: recent colours, swatch folders (primaries, process CMYK, greys, papers, inks and named palettes), a mixer with HSB, RGB and CMYK, an eyedropper for anything on screen, and a hex field. Use as inks applies a whole folder.

Brand palettes load from an Adobe .ase file (export one from Illustrator, Photoshop or InDesign: Swatches › Save Swatch Exchange), a GIMP .gpl, a .json, or any .css or .txt with hex codes in it. Ink by decides which ink each cell gets; Blocks fills the cells with ink and cuts the type out of them. Type blend sets how type sits over a backdrop.

Grid and motion

The frame is a grid of strips (columns when the direction is vertical, rows when it's horizontal), each cut into cells. Every cell has a place on a wave. As the wave passes, cells swell and their neighbours give way.

Row lag, Column lagHow far behind its neighbour each row or column runs, as a fraction of a wave. Small offsets ripple; large ones scatter.
StretchHow far cells can collapse. At 1 they almost vanish.
SwellAbove 1, most cells stay small and a few swell; below 1, most stay large.
WaveformSine, saw, seeded noise or steps.
LungsLets the columns (or rows) swell too.
SeedEvery random choice comes from it. Same seed, same result.

Golden section

Set Layout to Golden section and the frame is cut into a spiral of golden rectangles: each cut takes 1/φ (0.618) of the long side, leaving a smaller golden rectangle to cut again, turning a quarter each time. Choose the First cut, the Spiral's direction and the number of Golden cuts; Golden swing lets the cuts breathe away from φ and back as the wave passes (0 holds them exactly golden). With Fit set to Keep proportions (editorial), words sit in their blocks at their true proportions, aligned like a page; with Ink by: Blocks the blocks themselves take the inks.

Shape fill

Pick any mark as the Shape and the type fills its silhouette, or flows around it. Fill cuts the type to the edge or keeps only whole cells; Around makes the shape negative space. Shape size, across and down can be keyframed, so a logo can grow, pulse or sweep through the type. Thin shapes like a signature want many small cells: try 30 or more columns.

Keyframes

Every number and colour has a small diamond beside its name. Click it to set a key at the playhead; the name turns to the accent colour. Move the playhead and change the value to set another. Under the stage, each animated setting gets a lane: drag keys to move them, double-click a key to change its easing (smooth, linear, hold), select one and press Delete to remove it.

Keyframes play decides how the timeline maps onto the loop:

  • Boomerang plays forwards over the first half of the loop and back over the second. It always ends where it began, so it's always seamless.
  • Loop, easing back plays forwards, then eases from the last key round to the first.
  • Loop, jumping back plays forwards and cuts back to the start.

Effects

Applied in this order, each off at zero:

KaleidoscopeFolds the frame into mirrored wedges, turning a whole number of times per loop.
LiquidThe frame seen through moving water.
MeltColumns drip from a held top edge.
HalftoneDots, squares or lines at any screen angle, with dot gain. Drawn as vectors.
PhotocopyGeneration loss: softening, uneven toner, drum streaks, speckle and drop-out.
GrainFilm grain. Boil changes it every frame.
ReflectorMirrors the frame: left onto right, top onto bottom, four ways, or standing on a glossy floor with its reflection fading away.
CubeFolds the frame onto an isometric cube, or tiles it into tumbling blocks. Cube spin slides the artwork round the faces.
Pin buttonPrints the frame onto a campaign button on a table: domed shading, a rolled metal rim, gloss, paper fibre and wear. The artwork keeps moving; the button holds still.

Gradients and backdrops

The Stage group sits behind the type. Gradient makes a moving gradient from its own inks: Mesh (soft blobs of colour drifting on their own orbits), Linear (bands that turn) or Radial (rings that travel outwards). Drift is how many times it comes round per loop. Leave Content empty and it's a gradient maker on its own; add a little grain and export.

Drop an image or video anywhere on the page (not on the Marks row) and it sits behind the type. Set the format first: to reframe a 16:9 video as 9:16, pick Vertical and set Fit to fill the frame. Video speed sets the playback rate; the video restarts with each loop. In exports, every frame waits for the video to reach its exact time. Backdrops stay in your browser; the patch only names them.

Everything is rendered offline, frame by frame, through the same code as the preview, so a slow computer makes a slower export, never a stuttering one. Exports carry on in a background tab.

Patches

A patch is the complete recipe for a loop, as a small JSON file. Like a patch sheet for a synthesizer: hand it to someone and they get exactly the same thing.

{
  "name": "Campaign button · Hire Nick",
  "instrument": "elastic",
  "version": "0.4.0",
  "seed": 1984,                       // every random choice comes from this
  "params": {                         // the controls; anything left out takes its default
    "format": "square",
    "content": "HIRE\nNICK",
    "font": "Anton",
    "palette": ["#F3EBD8", "#E4372B"],
    "shape": "button"
  },
  "keys": {                           // keyframes, t from 0 to 1 along the timeline
    "shapeScale": [{ "t": 0, "v": 0.9, "ease": "smooth" }, { "t": 1, "v": 1 }]
  },
  "marks": { "button": "<svg …>" }   // SVG marks travel inside the patch
}

Patches are forgiving: unknown settings are ignored, values are clamped into range, and missing ones take their defaults. So a patch you write by hand, or one an AI writes from a description, always opens. The full list of settings, with their ranges, is in instrument.json.

Presets

Save keeps a patch in your browser. To make it a preset everyone gets, run the machine locally (below), set it up, name it, and press Add to presets. It's written into web/instruments/elastic/presets/ and listed in index.json, ready to commit. By hand: put the patch file in that folder, add its name to index.json, and run npm run check.

A studio can keep its own fork with its own presets, so a team gets a menu of on-brand starting points.

On your website

Press Copy embed code in the machine, or write it yourself. It runs the real engine, so it's a few kilobytes rather than a video, sharp on any screen, and it rests while it's scrolled out of view. Visitors who ask their system for reduced motion get the still frame.

<div id="hero" style="aspect-ratio: 16 / 9"></div>
<script type="module">
  import { mount } from "https://createomatic.xyz/instruments/elastic/embed.js"
  mount(document.getElementById("hero"), "/patches/hero.json")
</script>

mount takes a patch object or the address of a .json, plus an optional backdrop: mount(el, patch, { backdrop: "/clip.mp4" }). It returns a function that stops it. For the most control, host the web/ folder yourself. Fonts from the font library and SVG marks work anywhere; an Adobe kit needs your domain added to the kit.

Rather a file? Export WebM and use <video autoplay muted loop playsinline>.

In Figma

  • Stills: export PNG and drag it onto the canvas.
  • Motion: drag a GIF or MP4 onto a frame. GIFs play in prototypes; video is supported on paid Figma plans.
  • Colour: export your Figma palette as hex codes and paste them into Inks, or load them as a brand palette.
  • Logos: copy a vector from Figma as SVG (Copy as › Copy as SVG), save it as a .svg file, and drop it into the machine as a mark.

With Claude and other agents

The machine can be operated from code exactly as it's operated by hand. In the browser, window.instrument exposes it:

instrument.setPatch({ params: { content: "HELLO", format: "square", halftone: 8 } })
instrument.set("ease", 3.2)
instrument.key("copier", 0, 1); instrument.key("copier", 1, 0)
const png = await instrument.render("png")   // a Blob, no download
await instrument.export("mp4")               // downloads

Because every control is described in instrument.json, an agent such as Claude Code can turn a brief ("a slow, pink, photocopied loop of our tagline, 9:16") into a patch, open it, look at it and refine it. The repository includes a CLAUDE.md for exactly that.

Running it yourself

git clone https://github.com/thisisnickdecker/create-o-matic
cd create-o-matic
npm run dev        # http://localhost:4173
npm run check      # manifests, presets and tests

That's all: Node 22 or later, no install, no build. The site is the web/ folder, as static files. To publish your own copy, connect the repository to Cloudflare Pages (or any static host) with web as the output directory and no build command.

Writing an effect

An effect is one file in web/packages/core/effects/. It declares its controls and draws onto the finished frame:

export default {
  id: "invert",
  label: "Invert",
  params: [{ key: "invert", label: "Invert", type: "number", min: 0, max: 1, step: 0.01, default: 0 }],
  active: (p) => p.invert > 0,
  apply(ctx, p, { t, frame, scale, seed, background }) {
    ctx.globalCompositeOperation = "difference"
    ctx.globalAlpha = p.invert
    ctx.fillStyle = "#fff"
    ctx.fillRect(0, 0, ctx.canvas.width, ctx.canvas.height)
    ctx.globalAlpha = 1
    ctx.globalCompositeOperation = "source-over"
  },
}

Add it to the list in effects/index.js and to the instrument's "effects". Its controls, keyframes, presets and agent access come with no more code. Two rules keep loops perfect and exports faithful: anything that moves completes whole cycles as t goes from 0 to 1, and sizes are measured in output pixels times scale.

What it can't do yet

  • Bend or melt individual letter outlines. Melt and liquid move pixels, so true glyph distortion and SVG or PDF export are next.
  • Sync to audio.
  • Reorder effects, or use one twice.
  • Carry fonts, images or videos you've added from one computer to another: add the files again.
  • Run liquid, melt and photocopy in real time at full size. They're computed on the CPU, so the preview lightens while they play; exports are full quality.
